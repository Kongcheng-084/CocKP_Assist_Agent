## 0.12.0 描述墙

- 事实核对 → 描述，新建文字卡片，标题、概述与正文自动保存。选择氛围/篇幅后确认调用当前 AI 配置；仅发送概述，不读取整部模组。
- 生成结果保存为独立草稿，可采用或丢弃，不覆盖已有正文；正文支持手写与编辑，描述独立于事实/玩家公开批准。保存、历史与备份沿用项目机制。
- 请求失败或超时不自动重试；每次扩写最多等待三分钟。退出软件时未完成请求不会续跑，概述和已有文字保留。
- 扩写约束保留可观察内容，避免添加剧情事实与直接泄露秘密；使用前仍需 KP 核对。

- 文件完整读取由三次减少为一次，供校验、解析和本地保存共用；传给 PDF worker 的缓冲单独复制以防转移后失效。新项目使用新建的校对范围，直接初始化页面记录，省去逐页空查询。原文件哈希校验、50 MB / 200 页限制、逐页校对与来源检查保留。
- 文字提取增加实际待处理页数进度、当前页与取消状态，继续提取只处理剩余/失败页；完成明确报告本轮成功与失败页数。保留图片检测，不自动运行 OCR。逐页提取不再每三页重建整个 PDF 界面并重复渲染封面，非当前页处理后释放页面缓存。
- 修复主页面和导入弹窗同时显示 PDF 时，预览、进度及校对输入错误选中底层页面的问题，所有操作限定在当前 PDF 工作区。
- 隔离桌面回归覆盖真实文件首次/反复导入、读取中取消、保存中取消、模拟写入失败及重试、文字提取取消/继续和全部 49 页处理；核对原文件哈希与原项目未变。不调用 AI，也不写入用户正在使用的资料目录。性能数值仅为本机测试，不承诺所有设备或 PDF 相同速度。

## 0.10.0 场景地图编辑器

- 入口：事实核对 → 场景 → 地图。原卡片墙保留；每组提取记录可建多张地图。新建时可勾选放入全部场景，仅按行排列，不推断通道，不调用 AI。
- 左侧资料栏可搜索、筛选场景/人物/线索，通过拖放或加号放入画布。标记关联原事实 ID，正文和数值实时读取原事实；同一事实可摆放多次、放在多张地图上。移除标记不会删除事实。不同组同名卡片不会串组；原事实已移除时保留关联缺失提示。
- 画布支持缩放、平移、Shift 多选/框选、自由移动、拖角缩放、数值编辑位置和尺寸、颜色、网格吸附、复制、对齐、等距及锁定。详情使用不挤动画布的右侧面板。连接可设门/走廊/楼梯/秘密通道/路线/自定义、名称、说明、两端锚点和可拖动折点。
- 通道默认 KP 自定义；可选择原文段落并填写逐字引文，手动核对。引文不匹配或来源过期时不可确认，已有关系显示待核对。连接、布局与事实确认/玩家批准分开，单纯编辑地图不会使备团包失效。画布尺寸不表示实际距离，无可靠尺寸不提供比例尺。
- 底图支持本地 PNG/JPEG/WebP 和当前 PDF 的页码选择、鼠标框选裁切。全程本地渲染，保存 PNG 资产及 PDF 页码/归一化裁切范围。可调整位置、尺寸、旋转、透明度并锁定；替换/移除底图保留标记坐标与原图占用范围。取消导入后不会应用迟到结果。
- 图片输入不超过 25 MB，解码后归一化至最长边 4096、总像素 800 万以内，保存 PNG 不超过 6 MB。项目底图文件总额 80 MB（含为本机撤销/历史保留的旧图片）；每组 100 张地图，单图 2000 标记/4000 连接。项目 JSON 仍受 15 MB 限制，超限明确报错。备份检查压缩前 160 MB/压缩后 100 MB，避免导出不可恢复的文件。
- 独立 maps[groupId] 数据保存地图、当前地图及各图视野；本机编辑历史支持撤销/重做，跨组互不影响。图像以哈希文件保存在项目目录 map-assets，不保存任意远程地址。自动保存、项目历史及完整备份恢复保留地图；备份携带当前引用的底图，恢复时同步重映射提取组编号，不含密钥。撤销/重做栈为当前会话数据，重开不保留。
- 可导出 KP PNG 地图（含底图与标记/关系，最长边 4096），不会自动导出给玩家。第一版是节点/区域标记编辑器，尚不包括建筑墙体绘制、AI 自动识别地点位置和真实比例绘图。
- 92 项自动化检查通过，覆盖地图数据、逐字出处、缩放坐标、隔离、历史与含图片备份恢复、输入保护。隔离 Electron 回归另验证真实指针拖动/缩放、资料栏拖放、锁定/吸附、多选/复制、端点及折点、PDF 裁切和图片导入、迟到结果取消、PNG 导出、多图视野、重载和旧卡片墙。所有测试使用合成资料与模拟 AI。

## 0.7.1 校验记录与侧栏

旧版把字段错误、原文匹配失败等全部概括为同一原因，并累计背景梳理及重复记录；这不等于同样数量的独立事实丢失。新版将当前待核对、背景历史、已恢复记录、自动校正、未采用的分类建议分开，显示标题、问题、批次和可定位的出处。旧记录没有保存失败正文，不能还原更具体的原始错误；读取时按现存信息重新整理报告，不猜测失败原因。

新提取保留校验未通过的候选草稿与问题细节。引文只允许两种可证明的本地校正：在既定出处唯一匹配可见字符的空格/换行差异，或在已提供原文中唯一匹配的出处编号；校正后使用原文的实际连续子串，不放宽词语、标点、否定或语义匹配，不进行模糊匹配。找不到原文、短引文无法定位及多义出处继续待核对；不以丢掉坏出处的方式放行整条卡片。

任务完成/停止后，可在待核对项中编辑正文、类别、规范实体名、必要性理由和逐条出处，在本机重新校验并恢复为待确认草稿；无模型调用，记录原失败项和校对时间。导入后标记 KP 修改，仍不自动确认或公开。校对保持已有草稿顺序；已导入墙的原卡不会自动覆盖，若合卡后正文有新增，界面提示手动同步。

右下角任务侧栏支持点击外部、再次点击任务条或按 Esc 收起；内部点击保持展开，后台任务继续。模态草稿预览提供手动刷新按钮，不抢输入焦点。本版通过 49 项自动化检查及隔离的打包界面回归（模拟 API），包括外部点击收起和本地校对恢复。

## 功能

- 本地模组书库，新导入创建独立项目，可归档和恢复。
- 项目文件自动保存、关闭前等待写入、保留最近 10 个保存版本。
- 原 PDF 在本机保存；OCR 模型和字体随包提供。原 PDF 按 SHA-256 校验，扫描校对记录按项目隔离。
- 原文、提取事实、马赛克证据墙、确认、备团包、桌边速查、Markdown/打印 PDF、玩家材料批准。
- `.kpproj` 完整项目备份与恢复，含原 PDF、页面校对、AI 草稿、事实和手记，不含 API 密钥。恢复创建新项目。
- OpenAI / DeepSeek 官方接口切换，各自独立保存模型和加密密钥，保留旧 OpenAI 配置。默认模型分别为 gpt-4.1-mini / deepseek-flash。DeepSeek 也可选择 deepseek-v4-pro。
- Windows 安全存储、本机配置文件导入（OPENAI_API_KEY / DEEPSEEK_API_KEY）、模型连接检查和本机 HTTP 代理。
- 不向网页服务器发送资料；仅点击提取时，由本机向选定官方服务商发送选中文字。发送前明确显示服务商；设置变化后须重新检查，不会跨服务商重试。
- DeepSeek 使用 Chat Completions JSON 输出，关闭思考模式，保留引用逐字校验；截断、空结果、余额不足、限流分别提示。

## 已知范围

0.6.0 支持全文或指定范围的后台提取。全文按保守的 token 估算预算安排全局梳理、详细提取、跨章核对；短文尽量提供完整原文，长文携带相邻原文、全局索引和原文证据。文本导入仍支持 12 万字符，PDF 仍支持 200 页 / 50 MB；单项 AI 任务设置 400 万字符的本机资源保护边界。扫描页没有文字时明确列出未读取页码，绝不静默截断。

任务在主进程运行，串行执行，独立保存于 userData/extraction-jobs。每批保存原文快照、结果、用量和处理状态，不在运行时覆盖项目文件；编辑、导航和切换项目不终止提取。任务固定项目 ID、服务商及模型，运行期间变更设置仅影响新任务。运行中的密钥只保留在内存，不写入任务文件。失败不自动重试；手动继续只处理剩余批次，输出截断时拆小失败批次。停止后迟到响应被丢弃。最小化继续，退出时保存检查点，重启须手动继续。

底部任务条和可收起侧栏展示进度；完成提示不弹模态窗口、不抢焦点。所有结果为草稿，引用逐字校验和导入时的来源版本检查保留；修改相关原文后需重提，未改动的其他草稿仍可导入。覆盖统计只计算详细提取目标，背景阅读不算已完成详细提取。页面覆盖不代表语义完整性，仍需 KP 核对。

`.kpproj` 备份包含任务快照、草稿和进度，不含密钥。恢复会生成新项目和新任务 ID，不影响原项目；未完成任务以停止状态恢复。旧项目和 0.5.1 备份仍可读取。网页中的浏览器数据不会自动转入本机应用，可重新导入原 PDF。项目历史恢复原事实，PDF 校对记录以当前版本为准，发现引用版本不符会撤回对应批准。

本版使用 Electron 的隔离预加载接口，渲染层无 Node 权限，禁止打开外部任意网页、拒绝设备权限，API 密钥仅在主进程解密。所有打包清单均排除开发配置、密钥和测试资料。

## DeepSeek 使用

应用设置 → AI 服务商选择 DeepSeek → 安全保存自己的 DeepSeek API Key → 保存并测试。连接测试仅检查认证和模型列表；实际提取时仍会检查账户余额。接口使用 https://api.deepseek.com/chat/completions，模型参考 https://api-docs.deepseek.com/quick_start/pricing/ 。无需配置自定义地址。

运行 `npm test` 检查接口、任务、备份、PDF 与资料逻辑。`node scripts/run-background-ui.cjs` 在独立测试目录运行 Electron 界面回归，所有 API 响应在本机模拟，不读取真实密钥、不连接付费 API；测试脚本不进入发布包。当前验证覆盖超过 18000 字符全文、提取中编辑/切换项目、完成不抢焦点、陈旧引用拦截、停止/重启/重试、草稿不自动批准。尚未执行真实的 DeepSeek 付费全文提取，提取质量与实际费用仍需用户配置后验证。
